
# SpendWise Dashboard Shell

## Project Overview
SpendWise is a static personal finance dashboard built using HTML and CSS. It displays sample financial information in a clean, modern, responsive interface.

## Files

### 1. index.html
This file defines the dashboard structure, including:
- Sidebar navigation menu
- Dashboard header and user profile
- Summary cards for balance, income, and expenses
- Six spending categories
- Recent transactions
- Footer

Semantic HTML elements such as `header`, `nav`, `main`, `section`, and `article` organize the content.

### 2. style.css
This file controls the appearance and layout of the dashboard.

It includes:
- CSS custom properties for the color theme
- CSS Grid for the overall layout and card collections
- Flexbox for navigation, headers, and card contents
- Responsive media queries for tablets and mobile devices
- Hover and keyboard-focus animations
- A dark theme using `prefers-color-scheme: dark`

## Main Features
- Food, Transport, Rent, Entertainment, Savings, and Utilities cards
- Kenyan shilling (KSh) sample financial values
- Responsive layout below 768px
- Card transitions lasting 200ms
- Light and dark themes
- Keyboard-accessible focus styles

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. Resize the browser to test responsiveness.
4. Use Chrome DevTools Device Toolbar to test mobile layouts.
5. Enable your device's dark mode to test the dark theme.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS custom properties
- Media queries

## Project Scope
This is a visual dashboard prototype using static sample data. It does not yet include JavaScript functionality, a database, or live financial calculations.
